## HOW TO IMPLEMENT

**Email Provider:** Mailchimp, ConvertKit, or Substack

**Setup Steps:**
1. Create email template for each sequence
2. Set up automation triggers (Day 0, Day 1, Day 3, Day 7, Day 14, etc.)
3. Add tags: [early_access], [trial_user], [paid_user], [churned]
4. Create exit survey in app that returns reason, which triggers conditional email

**Metrics to Track:**
- Open rate (target: 40%+)
- Click rate (target: 15%+)
- Upgrade rate from Day 14 email (target: 15%+)
- Churn rate (target: <5% monthly)

**A/B Testing Ideas (Later):**
- Day 14 subject lines: "ends tomorrow" vs "time to decide"
- CTA buttons: "Upgrade Now" vs "See Hustle Details"
- Pricing emphasis: "One flip covers it" vs "Just $19/month"

---

## COPY NOTES

- All emails use "I" (Britt, personally) not "we" (Flippd company). Builds trust + feels authentic.
- Avoid: "leverage," "best-in-class," "innovative," "AI-powered" — too corporate for resellers.
- Use: "flip," "profit," "sourcing trip," "thrift store," "shelf," "comps" — real reseller language.
- All CTAs are clear and low-friction ("Reply here" / button link).
- No false urgency ("Only 3 spots left!") — violates DECISIONS.md on fake scarcity.
- Reference product-marketing-context.md objections section for pain points.
