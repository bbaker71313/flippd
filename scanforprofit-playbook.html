ScanForProfit Design Direction

The FLIP/PASS result card is the hero moment — make it unmissable at arm's length in a bright thrift store. FLIP = bold green flash. PASS = red. Profit number = largest element on screen. The existing Flippd used warm/cream (#f2ece0, Syne + IBM Plex Mono) — you can evolve this or go high-contrast dark. Either direction, keep Syne for headers (already yours, already distinct). Run all UI copy through the stop-slop skill before shipping.
