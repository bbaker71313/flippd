# Flippd v5.1 Release Notes

**Release date:** April 27, 2026  
**Status:** ✅ Production ready for early access

---

## What's New

### Auto-Injected API Key
- API key no longer requires manual entry
- Automatically set in `localStorage` on first page load
- Users can still change it via ⚙ settings if needed
- **Implementation:** `window.onload()` checks `localStorage.getItem('fif_api_key')` and auto-injects if empty

### Persistent Instructions
- "⚡ Start here" green instruction box now always visible
- Previously disappeared after first scan
- Removed hiding logic from `showSrcView()` and `logScan()` functions
- **UX benefit:** New users always see the "Scan → Inventory → List" workflow

## Known Limitations

1. **API key in code** — For early access only. For public launch, this will be replaced by Manus proxy backend.
2. **No eBay OAuth** — Currently uses Anthropic API only. Full eBay integration planned.
3. **No cross-listing yet** — Single platform (eBay) only. Poshmark, Mercari, Facebook Marketplace coming in Phase 2.
