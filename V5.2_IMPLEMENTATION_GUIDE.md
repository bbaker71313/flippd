# Flippd v5.2 — AI Power Listing Implementation Guide

This guide documents the AI Listing Generator feature: architecture, data flow, UX, and technical details for developers maintaining or extending the feature.

---

## Feature Overview

**AI Power Listing Generator** (Phase 2.1 complete) takes an inventory item and generates a ready-to-list eBay title, description, and condition note using Claude AI. All generated listings are stored persistently and can be exported to eBay CSV format in bulk.

**User workflow:**
1. Open an inventory item
2. Click "🚀 Listing" button
3. Select condition (New / Like New / Open Box / Used / Fair) and eBay category (one of 21 hardcoded categories)
4. AI generates title (80 chars), description (250-400 words), condition note (50-100 words)
5. Review and optionally regenerate
6. Save to item OR save + queue for export
7. Export all queued items to CSV → upload to eBay Seller Hub

## Data Model

### Item Structure (in localStorage)

```javascript
{
  id: 12345,
  sku: "SKU-ABC123",
  nickname: "Vintage Radio",
  category: "Electronics",           // Broad category (from CATEGORIES list)
  condition: "Used",
  dateAcquired: "2026-04-20",
  cost: 3.50,
  sellPrice: 24.99,
  notes: "Works great, all buttons functional",
  photos: ["data:image/jpeg;base64,..."],
  status: "Ready to Export",          // Unlisted, Listed, Sold, Ready to Export
  
  // NEW in v5.2:
  listing: {
    title: "Vintage Radio AM/FM Model XYZ Works Great",
    description: "This vintage radio is in excellent working condition...",
    conditionNote: "The radio has been tested and works perfectly...",
    ebayCategory: "Amplifiers & Preamps",  // Leaf category
    ebayConditionId: "USED_VERY_GOOD",     // Maps to eBay condition ID
    generatedAt: "2026-04-27T18:32:14.123Z"
  }
}
```

### Storage Key
- **localStorage key:** `flippd_items_v1` (shared with entire inventory)
- **Listings persist:** Once saved, `item.listing` object stays on the item forever
- **Backward compatible:** Items without a `listing` object are handled gracefully (collapsible section doesn't appear)

## State Management

### Modal State Object

```javascript
let currentListingModal = {
  itemId: null,              // ID of item being edited
  stage: 'selection',        // 'selection' or 'preview'
  condition: '',             // Selected condition (New/Like New/etc)
  ebayCategory: '',          // Selected eBay leaf category
  generatedListing: null     // Generated copy after AI call
};
```

This object is:
- Created when modal opens (`openListingModal()`)
- Updated as user selects options
- Used during AI generation and save operations
- Reset when modal closes

## Key Functions

### `openListingModal(itemId)`
- Opens the modal for the given item
- Initializes `currentListingModal` state
- Sets initial condition from item's current condition
- Displays Stage 1 (Selection)

### `showListingSelectionStage()`
- Shows the condition + category selection interface
- Hides the preview stage
- Pre-fills condition field from item

### `proceedToPreview()`
- Validates that both condition and category are selected
- Calls `generateAndShowPreview()`
- Shows loading spinner during generation

### `generateAndShowPreview()`
- Calls `generateListingWithAI(item, condition)` via Claude API
- Stores result in `currentListingModal.generatedListing`
- Displays character counts for each field
- Shows four action buttons: Regenerate, Save to Item, Save + Export, Cancel

### `generateListingWithAI(item, condition)`
- Main Claude API call function
- **Input:** item object + condition string
- **Prompt structure:**
  - Item nickname, category, condition, user notes
  - Category-specific hints (e.g., "focus on materials for furniture")
  - Strict requirements for length and format
  - "Respond ONLY with valid JSON" directive
- **Output:** Parsed JSON with title, description, conditionNote
- **Error handling:** Throws if JSON parsing fails
- **Character limits enforced:** Truncates to 80/1500/500

### `regenerateListing()`
- Re-runs `generateAndShowPreview()` with same condition + category
- Gets a new variation of generated copy
- No API calls or data changes yet

### `saveListing(exportCsv = false)`
- Saves the generated listing to the item's `item.listing` object
- If `exportCsv = true`: also sets item status to "Ready to Export"
- Persists to localStorage
- Closes modal and re-renders inventory
- Shows toast confirmation

### `exportListingsToCSV()`
- Finds all items with `status === 'Ready to Export'` AND `item.listing`
- Generates CSV file in exact eBay format:
  - Header rows (#INFO lines per eBay template)
  - One row per item with column mappings
  - Category ID looked up from `EBAY_LEAF_CATEGORIES`
  - Condition ID looked up from `EBAY_CONDITION_IDS`
  - Description wrapped in `<p>` tags for eBay HTML support
  - Proper CSV escaping (quotes, commas, line breaks)
- Triggers browser download: `eBay-listings-YYYY-MM-DD.csv`
- Updates item status: `Ready to Export` → `Listed`
- Shows toast: "✓ Exported N listings"

### `toggleListingDetail(itemId)`
- Toggle visibility of collapsible listing preview in inventory cards
- Used in inline display of saved listings

## AI Prompt Structure

The prompt sent to Claude for listing generation:

```
You are an expert eBay reseller writing product listings. Generate a title, description, and condition note for this item.

Item name: [item.nickname]
Category: [item.category]
Condition: [selected condition]
Seller notes: [item.notes or "No additional notes"]

Focus on: [category-specific hint, e.g., "functional, tested, specifications" for Electronics]

STRICT REQUIREMENTS:
- Title: max 80 characters, eBay-optimized keywords first
- Description: 250-400 words, bullet points for key details, mobile-friendly
- Condition Note: 50-100 words, specific about condition

Respond ONLY with valid JSON (no markdown, no backticks):
{
  "title": "...",
  "description": "...",
  "conditionNote": "..."
}
```

### Category-Specific Hints

Different categories get different emphasis:
- **Electronics:** "functional, tested, specifications"
- **Clothing:** "fabric, fit, brand, styling"
- **Shoes:** "size, brand, condition, fit"
- **Home & Garden:** "materials, dimensions, functionality"
- **Collectibles:** "authenticity, rarity, condition"
- **Toys & Hobbies:** "completeness, vintage value, condition"
- **Books:** "author, edition, binding, condition"
- **Sporting Goods:** "brand, specifications, condition"
- **Jewelry & Watches:** "material, brand, specifications"
- **Other:** "condition, functionality, quality"

## eBay CSV Export Format

### Exact format required by eBay:

```
#INFO,Version=0.0.2,Template= eBay-draft-listings-template_US,,,,,,,,
#INFO Action and Category ID are required fields...
#INFO After you've successfully uploaded...
#INFO,,,,,,,,,,
Action(SiteID=US|Country=US|Currency=USD|Version=1193|CC=UTF-8),Custom label (SKU),Category ID,Title,UPC,Price,Quantity,Item photo URL,Condition ID,Description,Format
Draft,[SKU],[CATEGORY_ID],[TITLE],,,[SELL_PRICE],1,,[CONDITION_ID],[DESCRIPTION],FixedPrice
```

### Column mappings (in code):
- **Action:** "Draft" (hardcoded)
- **Custom label (SKU):** item.sku (or empty)
- **Category ID:** Looked up from EBAY_LEAF_CATEGORIES[item.listing.ebayCategory]
- **Title:** item.listing.title (max 80 chars, truncated in modal)
- **UPC:** Empty
- **Price:** item.sellPrice
- **Quantity:** 1 (hardcoded)
- **Item photo URL:** Empty (user photos are local, not in CSV)
- **Condition ID:** item.listing.ebayConditionId
- **Description:** item.listing.description wrapped in `<p>` tags
- **Format:** "FixedPrice" (hardcoded)

### CSV Escaping Rules:
- If cell contains comma or quote: wrap entire cell in double quotes
- If cell contains quote: escape with double quotes (`"` → `""`)
- Line breaks in description are preserved and wrapped in tags

## UI Components

### Modal HTML Structure

The modal (`#listing-modal`) has two main sections:

**Stage 1: Selection**
- Hidden by default
- Shows when modal opens
- Contains:
  - Item nickname display
  - Condition `<select>` (#listing-condition-select)
  - eBay category `<select>` (#listing-ebay-category)
  - "Next → Preview" button

**Stage 2: Preview**
- Hidden initially
- Shows after generation
- Contains:
  - Loading spinner (#listing-loading)
  - Generated content display (#listing-preview-content) with:
    - Title + character count
    - Description + character count
    - Condition note + character count
  - Error message area (#listing-preview-error)
  - Four action buttons:
    - ⚡ Regenerate
    - 💾 Save to Item
    - 📤 Save + Export
    - Cancel

### Inventory Card Listing Display

When `item.listing` exists:
- Shows collapsible section: "▼ View Generated Listing"
- Displays title, description excerpt (first 100 chars), generation date
- Uses small font size (10px) to fit in card without clutter

### 🚀 Listing Button
- Appears on every inventory item card
- Gold/accent color (rgba(212,168,67,0.15) background)
- Triggers `openListingModal(item.id)` on click
- `event.stopPropagation()` prevents card click-through

## Error Handling

### API Errors
- **Invalid JSON response:** "Error: Invalid response format"
- **API call fails:** Displays error message from API
- **Invalid access code (401/403):** "Invalid or expired access code"

### User Validation
- **Missing condition or category:** "⚠️ Select both condition and category"
- **No Ready to Export items:** "⚠️ No listings ready for export"

### Display:
- Error messages shown in red text in preview area
- User can still click "⚡ Regenerate" to retry
- Helpful toast messages on successful save/export

## Performance Notes

- **Single API call per generation:** `generateListingWithAI()` makes one Claude API call, returns title + description + condition note in one response
- **No streaming:** Response is fully generated before displaying to user
- **Character limit enforcement:** Client-side truncation to 80/1500/500 chars prevents eBay rejection
- **Local storage only:** No server calls except Claude API — all inventory data stays in browser localStorage
- **CSV generation:** Client-side, no server involved
